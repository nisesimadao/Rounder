macOS menu-bar utility

Round the screen.

Rounder softens sharp external displays and older MacBook corners with a tiny overlay app. It stays local and does not use Accessibility or Screen Recording permission.

Download Rounder GitHub

Sharp corners are a small daily mismatch.

What it does

Rounder fixes the edge of the display without taking over the Mac. It draws borderless corner overlays above the desktop, then gets out of the way.

01

No extra privacy permissions

No Accessibility permission, Screen Recording, Automation, or network access.

02

Live settings

Radius, color, corner selection, presets, and glow changes apply while running.

03

Multi-display

Choose which displays get rounded and keep external monitor desks consistent.
