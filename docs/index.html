Rounder

Download Rounder View source

Sharp display corners, softened in software.

Rounder draws lightweight overlay windows at the screen corners. It is built for external monitors, multi-display desks, and older MacBooks that do not have physically rounded panels.

Private

Runs locally and stores settings in UserDefaults. No telemetry, no network dependency.

Instant

Radius, color, corner selection, presets, and gaming glow update while the app is running.

Quiet

Lives in the menu bar and keeps out of the Dock after setup.

Small surface area, enough control.

Per-corner control

Enable only the corners you need, then tune radius and shape from one settings window.

Multi-monitor aware

Choose the displays Rounder covers. Newly connected monitors are picked up automatically.

Gaming glow

A controlled rainbow glow mode for setups where subtle is not the point.

Install the app, open once, then leave it in the menu bar.

1. Download Rounder.zip
2. Move Rounder.app to Applications
3. Right-click and choose Open on first launch
macOS 14.6 or later. Built with SwiftUI and AppKit.
