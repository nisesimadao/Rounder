The real corner.

What it does

Rounder draws borderless corner overlays above the desktop, then gets out of the way. Settings stay local, and everything lives in the menu bar.

01

No permissions

No Accessibility permission, Screen Recording, Automation, or network access.

02

Live tuning

Radius, color, corner selection, presets, and glow changes apply while running.

03

Multi-display

Choose which displays get rounded and keep external monitor desks consistent.

Small app. Specific job.

Controls

SET

Pick the displays, radius, shape, and corners you want.

SAVE

Use presets for subtle corners, all corners, or gaming glow setups.

LEAVE

Keep it in the menu bar. No Dock icon after setup.

Install once.

Install

Download the latest release and move Rounder.app to Applications. The app is unsigned, so Gatekeeper asks once on first launch — right-click and choose Open.
