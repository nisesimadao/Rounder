# FAQ

## Gatekeeper の警告が出るのはなぜですか？

Rounder のリリース版は ad-hoc 署名されていますが、Developer ID 署名と公証は行っていません。
そのため、macOS が初回起動をブロックする場合があります。

`Rounder.app` を右クリックして **開く** を選び、確認画面でもう一度 **開く** を選択してください。
必要な場合は、quarantine 属性を手動で削除できます。

```bash
xattr -dr com.apple.quarantine /Applications/Rounder.app
```

## アクセシビリティ権限や画面収録権限は必要ですか？

必要ありません。
Rounder はボーダーレスのオーバーレイウィンドウを描画するため、アクセシビリティ、画面収録、自動化などのプライバシー権限を使用しません。

## MacBook の内蔵ディスプレイで角丸が見えないのはなぜですか？

ノッチ搭載 MacBook の画面の角は、もともと物理的に丸くなっています。2.4.0 では Notched MacBook プリセットを適用すると、メニューバーを黒くしてノッチを目立たなくし、その下のアプリ領域を角丸にできます。外部モニターや古い MacBook では、Default プリセットで画面端の角丸を確認できます。

## メニューバーを黒くするには？

「設定 → プリセット」で Notched MacBook を適用してください。個別に設定する場合は、「角の表示」で「メニューバーを除外」と「メニューバーの背景を黒くする」をオンにし、「外観」で角の色を黒にして「適用」を押します。黒い背景は「ディスプレイ」で選択した画面に表示します。

文字色は macOS が壁紙に合わせて決めます。黒い背景で文字が読みにくくなる場合は、暗い壁紙に変えるか、背景の黒塗りをオフにしてください。Rounder はシステムの文字色を変更しません。

## フルスクリーンや Mission Control ではどうなりますか？

「メニューバーを除外」がオンの場合、画面固定の上の角丸はフルスクリーンの Space で画面上端へ移動し、通常の Space でメニューバー直下へ戻ります。Mission Control 中は黒い帯と上の角丸が同じフェードで隠れ、下の角丸は残ります。「視差効果を減らす」が有効な場合は、アニメーションせず切り替えます。

## 固定方法やメニューバー設定もプリセットに保存できますか？

2.4.0 では、角の見た目に加え、画面への固定・仮想デスクトップへの固定・メニューバーの除外・背景の黒塗りも保存します。初期プリセットは Default・Virtual Desktops・Notched MacBook の3つです。古いプリセットファイルも読み込めます。アップデート時もユーザーが作成したプリセットは残します。

## Rounder はデータを送信しますか？

送信しません。
Rounder はテレメトリや分析データを収集しません。
設定は macOS の `UserDefaults` にローカル保存します。

## ダウンロードを検証するには？

GitHub Releases では、配布 asset の SHA-256 digest を確認できます。
最新リリースで `Rounder.zip` の詳細を開き、GitHub に表示される digest とローカルで計算したチェックサムを比較してください。

```bash
shasum -a 256 Rounder.zip
```
